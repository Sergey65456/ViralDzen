# Как открыть таблицу

GitHub **не показывает HTML как страницу**: если кликнуть `viral.html` в репозитории, виден исходный код, а не таблица. Это нормально, файл не сломан.

## Открыть в браузере (ссылка)

- [Таблица ниш](https://rawcdn.githack.com/Sergey65456/ViralDzen/01d8580/reports/dzen-topics/viral.html)
- [Вирусные примеры](https://rawcdn.githack.com/Sergey65456/ViralDzen/01d8580/reports/dzen-topics/viral-examples.html)

Запасная ссылка на ту же таблицу: [jsDelivr](https://cdn.jsdelivr.net/gh/Sergey65456/ViralDzen@01d8580/reports/dzen-topics/viral.html)

## Скачать и открыть с компьютера

1. Откройте [viral.html как Raw](https://github.com/Sergey65456/ViralDzen/raw/01d8580/reports/dzen-topics/viral.html)
2. Сохраните файл (`Сохранить как…` → `viral.html`)
3. Дважды кликните скачанный файл — откроется Chrome или другой браузер
